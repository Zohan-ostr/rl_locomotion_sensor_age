# Сохранённые результаты

Для первого знакомства откройте [общий отчёт](../reports/REPORT.md),
[графики и таблицы](../reports/REPORT.md#readme). Здесь лежат исходные измерения.

| Каталог | Содержание |
|---|---|
| `baseline_h1/` | Штатная ходьба, версия upstream, лицензия, хеши, установка и видео |
| `pilot_h1/` | 548 пилотных эпизодов, seed 0–9; исходный M и контрольные методы |
| `m2_h1/` | Ускорительные кандидаты |
| `m2_periodic_h1/` | Периодические кандидаты |
| `m2_followup_h1/` | Циклические и затухающие кандидаты |
| `m2_hybrid_h1/` | Раздельный выбор моделей и составной M2 |
| `m2_validation_h1/` | Проверка seed 10–19, регрессии и frontend |
| `m2_h1_setup/` | Реальные команды, зависимости и логи разработки M2 |
| `m3_h1/` | Диагностика, обучение, четыре кандидата, замороженный M3, закрытая серия, графики и CSV |
| `interactive_h1/`, `interactive_h1_checks/` | Ограниченная демонстрация и её проверки |
| `sandbox_h1_checks/` | Свободный режим, проверки клавиш, неудачные варианты стояния |
| `repository_maintenance/` | Команды, проверки и журнал текущего оформления |
| `setup/` | Локальные логи установщика и smoke-запуски; игнорируются Git |
| `user_runs/` | Рекомендуемое место новых пользовательских запусков; игнорируется Git |

В эпизодах `summary.json` хранит условия, метрики, версии и SHA-256;
`trajectory.csv` — временные ряды; `signals.npz` — массивы входов, действий
и показаний. `inputs/` содержит парные начальные состояния и расписания.
`source_snapshot/` сохраняет код фактически выполненной стадии.

Повторы для видео, технические проверки и варианты параметров не являются
дополнительными независимыми seed. В исследовании M3 seed 100–139 открыты
после фиксации модели; статус и измерения — в [отчёте M3](m3_h1/REPORT.md).
Для нового подбора они уже не являются закрытой проверкой.
Сохранённые серии не удалены при очистке: они нужны для проверки отрицательных
результатов. Окружение и upstream находятся вне этого дерева и игнорируются Git.
