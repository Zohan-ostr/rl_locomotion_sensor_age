# Исключённые диагностические запуски

Первые smoke/headless20/video20 выполнены до обнаружения того, что checkpoint
содержит LSTM с изменяемой памятью. Пробный forward нулевого наблюдения для
проверки размеров изменял hidden/cell state до первого физического шага.
Поэтому эти запуски не воспроизводили штатную нулевую память при старте.

Логи, CSV, manifests, видео и старый runner SHA-256 сохранены для аудита.
Ошибка исправлена: runner сохраняет buffers до probe и восстанавливает их
после него с проверкой точного совпадения. Итоговые запуски находятся на
уровень выше; эти ранние данные не включаются в итоговые метрики.
